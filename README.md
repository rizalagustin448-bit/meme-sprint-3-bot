A fake GitHub PR screenshot meme: an AI agent opens a pull request titled "Fix everything", then reviews its own PR and requests changes on it — "Changes look risky. Please ask the author." The author is itself, so the merge stays blocked forever.

## Run it

```sh
python3 main.py
```

Renders deterministically to `/output/entry.png` (1024x1024 PNG, no external assets).
